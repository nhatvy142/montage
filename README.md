# Montage.
A team with aesthetic mindset — film, packaging & AI imagery from Saigon.

Single-page portfolio site, served with GitHub Pages.

## Update the work
1. Upload images to the `work/` folder.
2. Edit `index.html`, search for `EDIT YOUR PORTFOLIO HERE`, and add the paths to `images:[...]`.
3. Commit. The site refreshes in about a minute.
